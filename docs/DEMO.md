# KONE-ELEV-001 Competition Demonstration Guide

## Overview
This guide provides the exact step-by-step procedure to execute the live competition demonstration scenario: **KONE-ELEV-001 Bearing Degradation & Automated Maintenance Resolution**.

---

## 1. Demo Setup & Initialization

1. Start the FastAPI Backend:
   ```bash
   cd backend
   uvicorn app.main:app --host 0.0.0.0 --port 8000
   ```
2. Launch the React Frontend:
   ```bash
   npm run dev
   ```
3. Open Dashboard in Browser:
   `http://localhost:3000` (or production Netlify `https://eloquent-eclair-c69e60.netlify.app`)

---

## 2. Step-by-Step Competition Scenario Execution

```
[ Step 1: Select KONE-ELEV-001 ]
Select 'KONE-ELEV-001' from topbar dropdown. Verify status is healthy and overall health is 90+.

[ Step 2: Configure Simulator ]
In 'Simulator Controls' bar, select:
- Scenario: 'BEARING_DEGRADATION'
- Speed: '1.0x' (or 2.0x for accelerated demo)
Click 'Start'.

[ Step 3: Observe Telemetry Escalation ]
Navigate to 'Live Monitoring' or observe KPI cards:
- Vibration rises from 1.5 mm/s to 4.8 mm/s, then spikes above 8.5 mm/s.
- Motor temperature increases from 42°C to 78°C+.
- Current draw climbs from 11.5 A to 18.5 A+.

[ Step 4: AI Anomaly Detection Trigger ]
Within 15–30 seconds:
- Status transitions from HEALTHY ──► WARNING ──► CRITICAL.
- AI Fault Detector flags: 'Bearing Degradation' (Confidence: 94.2%).

[ Step 5: Root Cause Analysis (RCA) Verification ]
Navigate to 'Root Cause Analysis' page:
- View interactive diagnostic chain:
  Abnormal Vibration ──► Motor Temp Increase ──► Current Drag ──► Bearing Degradation
- View isolation confidence score and contributing factors table.

[ Step 6: Health & RUL Update ]
Navigate to 'Elevator Health' page:
- Overall Health Score drops from 89% to 42%.
- Bearing Component Health drops to 42%.
- RUL estimate updates to '12 Days' (288 Hours).

[ Step 7: Critical Alert Generation ]
Navigate to 'Alerts & Notifications':
- Critical alert 'AL-901: Bearing failure risk is 94%' is created.
- Click 'Acknowledge Alert'.

[ Step 8: Maintenance & Technician Dispatch ]
Navigate to 'Maintenance' & 'Technicians' pages:
- Maintenance Task 'MT-1042: Bearing Degradation' is auto-generated with Critical priority.
- Recommended technician 'D. Suresh' (Specialization: Bearing & Vibration Analysis) is assigned.

[ Step 9: Verify Real-Time WebSocket Streaming ]
Confirm that telemetry charts, health gauges, and alert banners update automatically via WebSocket broadcast without requiring manual page refresh.
```
